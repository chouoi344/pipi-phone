# 模型配置页验收规则

## 入口和布局

- 先按正式小手机的手机端规格做，沿用现有整体 UI、字号、颜色、间距、分隔和控件样式。桌面以手机宽度预览。AstrBot 可参考操作和字段，优先采用用户最新确认的小手机方案。
- 首页保留「屁屁自己的站」的一键配置、七个模型分类、用途说明和服务商数量。每个分类从分区右侧的「添加服务商」进入。服务商类型选择整行可点，右侧省去箭头。
- 一键配置页只显示分组密钥和一个底部配置按钮。对话分组保存密钥后由用户在卡片里获取并选择模型，填写密钥的其他分组自动添加对应预设。留空的分组和已有用途选择继续生效。
- **同一个操作只放一个入口。** 展开、收起用服务商卡片的标题行和同一行的箭头。更多菜单提供删除。已配置的模型在所属服务商卡片里查看和管理，对话模型用途在「小手机」设置里选择。
- 「小手机 → 对话设置」依次显示对话模型、回退模型、图片转述模型和语音模型。主对话和图片转述由用户指定，图片转述只列可识图的对话模型。语音模型供朗读和合成，录音转写和语音条理解在模型页的「语音转文字」分类中设置。
- 模型选择、添加服务商、模型参数和一键配置统一从底部弹出。长表单在弹窗内滚动，关闭后回到原位置。

## 配置和保存

- 「已配置的模型」每行上方显示型号和能力，下方左侧是启用开关，右侧是本分类的操作按钮。两套皮肤在窄屏网页和旧安卓网页内核均应如此；可用模型的名称与添加按钮同排。
- 新增服务商时在原页自动展开。卡片标题随用户填写的名称更新，已填写的接口地址显示在下方。图标对应服务商的接口类型，尺寸沿用小手机。展开后在同一卡片填写资料、获取和搜索模型，也可以手动添加型号。
- 可用列表显示这次接口返回且尚未添加的型号，获取失败时清除旧候选。已配置和可用两组各自分页，每页 20 条。可连续添加多个。模型弹窗确认能力、请求参数和上下文容量，容量填 0 自动识别。已识别的能力自动勾选；未知型号默认全开，可以手动调整。已有且适用的高级参数收在对应位置。
- **一个编辑范围只有一个主保存按钮，放在底部。** 模型弹窗的「确认」先放入当前卡片，卡片底部的「保存」再统一提交。测试连接和参数编辑都在模型那一行，生成图片分类省去连接测试。

## 资料和验收

- 保留原有服务商、模型、用途选择与密钥。保存同一接口地址时，密钥留空表示沿用。停用模型时保留参数和用途设置，删除始终先确认。自家站点的删除只清除所选分组的密钥、模型及相关用途选择，顶部的一键配置可重新添加。
- 同页查询、保存、关闭弹窗与刷新保留原来的位置和适用的展开状态；切换分类从顶部开始。同一标签页刷新可恢复未保存的卡片草稿和搜索、分页，未提交的 API Key 留在原页面内存，刷新后可重新填写。先用隔离样本确认新方案，再接入正式页。交付检查手机和桌面宽度、实际按钮路径及已有资料保留，并复用原来的标签页。

# v0.4.5 原生功能依据与对照清单

研究日期：2026-11-14。范围：iPhone 微信 8.0.80 的本地页面、导航、控件与手势；本小手机中可独立实现的对应能力。本文只提供研究与静态对照，**没有操作真实微信、没有运行本项目或浏览器、没有给任何项目功能判定通过**。代码观察是本轮并行改动开始前的快照，后续是否修好须由执行者重新检查。

## 证据怎么读

| 等级 | 含义 | 可以证明什么 | 不能证明什么 |
| --- | --- | --- | --- |
| A1 | 用户提供的目标原生图/明确确认 | 图中可见状态，或用户明确确认的触发方式 | 未出现的页面、动画、返回、菜单和灰度状态 |
| A2 | 腾讯当前第一方文字，或官方开发者营销图 | 明文描述的功能/路径，或图中广义结构 | 8.0.80 所有账号相同、像素尺寸、未展示交互 |
| B | 明确转述微信派/腾讯客服的可信报道 | 候选原生行为、历史或近期变化；可帮助发现漏项 | 原文未核对部分、目标账号已收到灰度、目标版本像素 |
| C | 原作者开源实现、已认可作图模拟器 | 历史实现思路、控件分层和候选项 | 真实微信当前行为或原生验收结果 |
| U | 本轮未取得明确原生证据 | 需要补证据的测试点 | 不得据记忆、文件名或“常见交互”判为通过 |

**原生存在、项目可用、视觉一致是三个结论。** A2/B/C 只能按其限定使用；源码里有按钮不代表按钮可用，测试通过不代表图形与目标相同。本文表格里的“未见/待查”是初始静态观察，不是最终缺陷复验。

## 本轮最值得优先补查的遗漏

1. **消息与收藏多选**：当前腾讯说明明确存在，初始消息菜单只有引用/复制/收藏/删除等，没有多选；收藏详情有删除，列表没有长按/多选。应分别检查进入、选择、取消、返回和批量操作，不能用单条删除替代。[P1 §5.2.3/§5.2.7][P1]
2. **个人页拍一拍设置**：腾讯明确列为可编辑的个人信息，初始入口仍是 `coming-profile-pat`；目标后缀长度未查到可靠当代原文，不能把 2020 年的 8 字限制说成 8.0.80 规定。[P1 §5.3.1][P1]
3. **搜索不是过滤最后一条消息**：初始首页只匹配名字/备注和最后一条消息，聊天内只有关键词。全局结果分组、日期、图片及视频、文件、链接等应单列核查；本轮官方 FAQ 精确链接打不开，具体当前菜单仍待原生补证。[H1][H1]
4. **朋友圈入口分层和隐藏手势**：点击相机选择媒体、长按相机发纯文字；个人相册的时间筛选、消息盒子；长按作者头像设置朋友权限，都不是初始同一信息流/同一编辑器能覆盖的。[B1][B1] [C1][C1]
5. **发现页仍沿用旧目录**：初始有“摇一摇”，未见视频号/直播/听一听。可信报道展示腾讯客服答复称大陆微信发现入口已将摇一摇替换为听一听，海外 WeChat 存在差异。业务内容可列平台外范围，根页入口与显示状态仍需目标原生图核对。[B5][B5]
6. **好友资料设置少一层可做的能力**：初始未见星标朋友，朋友权限/黑名单/聊天背景均是待开放入口。星标有历史原作者源码，当前原生开关排布未取得；这些本地能力不能因为真实腾讯生态不可接入而整体忽略。[C2][C2]

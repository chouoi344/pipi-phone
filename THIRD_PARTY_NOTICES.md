## Evaluated but not incorporated

ZeroChat, AstrBot, SillyTavern, LovePhone Studio, Dinero.js and Farmhand were evaluated during planning. No source or media from these repositories has been copied into this prototype. They remain candidates for later evaluation; this application makes no plugin compatibility promise.

Reason for the prototype's small custom server: the inspected complete products have different frontends or storage models, and integrating them has not yet been validated. This initial iteration uses the existing Node HTTP, crypto and SQLite libraries to make the confirmed single-server workflow testable without inheriting a second application's unrelated features.

### Version 0.11.0 design-reference update

The preceding evaluation notes describe the earlier prototype. Version 0.11.0 uses AstrBot v4.29 as a design reference for provider/model assignments, staged message processing, compression, segmented delivery, action loops, scheduling and declaration-driven settings. The retained-recent-history ratio was checked against [AstrBot v4.29.0's compressor implementation](https://github.com/AstrBotDevs/AstrBot/blob/v4.29.0/astrbot/core/agent/context/compressor.py): it is based on the current request's estimated length, preserving complete rounds.

The engine is independently implemented in Node.js from the confirmed feature specification. No AstrBot or LivingMemory source code or media is included; neither application is a runtime dependency. This design reference does not promise compatibility with their plugins or APIs. Existing application and third-party license files are unchanged.

# 本地模型链路演示

这个演示使用真实应用页面、服务端接口和 SQLite 保存，只把外部模型换成本机 HTTP 固定响应。演示数据单独放在系统临时目录，不读取原有实例。未接入任何真实供应商，不验证生成质量或计费。

在项目根目录运行：

```powershell
node scripts/demo.cjs
```

- 应用：`http://localhost:51022/`
- 场景控制台：`http://localhost:51023/`
- 演示密码：`Pipi-local-demo-2026!`
- 真实监听地址为 `127.0.0.1`；应用使用 `localhost` 打开，避免覆盖通过 `127.0.0.1` 登录的其他本地实例 cookie。

启动输出包含本次 `dataDir`。每次普通启动创建独立新目录；保留这条路径即可恢复同一演示。先停止原演示进程，再运行：

```powershell
node scripts/demo.cjs --resume "启动输出中的 dataDir 完整路径"
```

恢复只接受系统临时目录中的 `pipi-local-demo-*` 目录，先解析实际路径，再检查范围；不会重置已有账号、模型配置或消息。数据目录会保留，方便检查与恢复。

演示实例在服务端固定允许当前本机模拟服务地址；运行中保存或恢复其他模型地址会被拒绝，已有外部模型地址的目录也无法作为演示恢复。角色主动消息和朋友圈后台生成同样受此限制。普通启动的应用不受演示地址限制。

## 点击试用

控制台有逐项操作说明和演示小票/音频下载。先打开应用登录，再回控制台选择场景并点「应用场景」。支持成功、3 秒延迟、首次失败后重试成功、HTTP 503、无效 JSON、空结果、连接中断和真实 45 秒超时。失败消息点击红色感叹号，使用应用原有的重新发送。

| 能力 | 真实链路 | 固定演示内容 |
| --- | --- | --- |
| 文本、朋友圈 | `/chat/completions` | 带「本地演示响应」的固定文字 |
| 图片聊天、账单草稿 | 图片随真实请求发送到同一端点 | 固定说明或 12.50 元草稿；确认后才入账，不识别图片内容 |
| 语音转文字 | multipart `/audio/transcriptions` | 固定转写说明，不识别录音内容 |
| 朗读 | `/audio/speech`，保存返回的音频 | 可播放的 0.45 秒提示音，不是真人语音 |
| 图像生成、自动记忆插件 | 尚未接入 | 演示没有补造接口，也没有选定插件 |

控制台的请求表记录真实命中的模型接口、场景、状态和耗时，不记录请求正文、录音、图片或请求密钥。演示角色和资料名称也有明确标记。

## 验证

```powershell
node --test tests/demo.test.cjs
```

专项有 10 个链路子测试及 2 个启动故障/恢复安全测试，Node 测试输出合计 13 项；包含真实 45 秒等待，约需 49 秒。覆盖四能力预设、模型列表/连通、文本与图片传输、保存与去重、账单确认、multipart 转写、有效 MP3 返回与保存、朋友圈、失败重试、等待状态与并发拒绝、异常、超时、同端口恢复后继续请求、运行中/恢复时拒绝外部模型地址，以及创建失败后恢复私网环境开关。HTTP 验证不代表已经检查真实麦克风、扬声器或真实模型服务。

代码自审核对了：固定服务路由不开放任意文件读取；场景修改要求同源 Origin；模型请求要求演示密钥；仅在演示进程启用私网模型地址并在退出/创建失败时恢复；恢复目录检查实际路径；启动、保存与恢复均检查允许的模型地址；日志不保存请求正文。原有实例、Docker 和正式模型密钥不参与本演示。

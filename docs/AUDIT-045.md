## 无模型预设的验证边界

演示通过真实网页、应用接口、请求解析、错误状态、重试及 SQLite 保存，只有模型服务返回固定内容。文本、图片、朋友圈、票据草稿、multipart 转写、语音合成均有真实本机 HTTP 测试。语音合成返回可解码的 0.45 秒提示音，不是生成的人声。

浏览器实际发送文字/图片、经历 503 再重试、生成角色动态、上传小票并核对 12.50 草稿、确认后入账、触发朗读接口。转写的 HTTP 链路通过；真实麦克风录音、系统授权和扬声器声音没有在本轮验证。生图及自动记忆插件尚未接入，没有制造假接口冒充实现。

独立审查还发现演示恢复配置可能转向外部供应商，以及初始化失败泄漏私网开关。现已修复：演示启动、运行中保存和备份恢复均限制当前本机服务地址；创建失败/关闭会恢复环境。正式程序的供应商配置不受这个演示限制。

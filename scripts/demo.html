本地模型链路演示

这是独立临时数据的演示实例。页面、请求解析、聊天状态、重试与保存使用真实应用代码；模型服务由本机 HTTP 模拟服务返回固定内容。没有连接外部模型，不产生模型费用。请只输入演示资料。

打开真实应用

演示登录密码：

应用内的资料名称和角色名称均带有演示标记。模型配置可在「我 → 设置 → 模型与服务」查看。

选择下一次模型请求的场景

切换只影响后续请求。延迟场景可检查等待提示和重复发送；超时保持真实应用的 45 秒等待。失败消息保存在聊天中，点击红色感叹号可重试。「首次失败，重试成功」会让该场景的第一次模型请求失败、后续请求成功。

语音和引用预设

在第一个演示角色中追加固定样本，保留现有演示内容。未转写语音可长按选择转文字，配合上方延迟、失败场景检查等待和重试；另有已存转写、图片引用、短链接和长文字引用。语音样本是提示音，文字为明确标注的固定演示结果。

在应用里点击试用

  1. 文本聊天：在微信页打开一个演示角色，发送任意演示文字，回复带有「本地演示响应」。刷新页面，确认消息仍保留。
  2. 失败与重试：切到「首次失败，重试成功」，发一条消息；点击红色感叹号，再点重新发送。原消息恢复成功，只增加一条回复。
  3. 图片聊天：下载演示小票 PNG，通过聊天「+ → 相册」上传。固定回复说明图片已经到达本地服务，不识别图片内容。
  4. 拍照记账：在「我 → 服务 → 现实账本 → 拍照记账」上传同一小票，检查固定的 12.50 元草稿，点击确认后才写入账本。
  5. 朋友圈：在「我 → 设置 → 朋友圈管理」使用角色生成动态，返回固定且有演示标记的文案。
  6. 语音转文字：通过聊天输入区麦克风录入一段话，真实录音会传到本地服务，结果固定为「本地演示转写…」，不识别录音内容。
  7. 朗读：长按模型回复，选择「朗读消息」。服务返回 0.45 秒合成提示音，用来检查音频请求、保存和播放，不模拟真人语音。下载提示音样本

图像生成和自动记忆插件尚未接入，本演示没有实现这些能力。真实供应商兼容性、真实识别质量和真人语音效果仍需选定服务后验证。
